Debugging challenge

Stop the out-of-bounds read

A sensor gateway intermittently crashes while parsing packets received over UDP. Repair the parser without changing the wire format.

Requirements

  • Validate the declared payload length.
  • Reject truncated headers safely.
  • Preserve valid zero-length payloads.
  • Do not allocate heap memory.

Hint 1 of 4 · Conceptual nudge

Before reading any header field, prove that the buffer contains the complete header.

parser.cparser.hTestsNotes
int parse_packet(const uint8_t *buf, size_t len) {
  const packet_header_t *header =
      (const packet_header_t *)buf;

  uint16_t payload_len = ntohs(header->length);

  if (payload_len > len) {
    return PARSE_TRUNCATED;
  }

  return process_payload(
      buf + sizeof(*header), payload_len);
}

5-minute mini-lecture

Validate the container before its contents

A length field is untrusted data inside an untrusted container. First prove the header itself exists. Then convert and validate its declared length against the bytes remaining after the header—not against the original buffer length.
